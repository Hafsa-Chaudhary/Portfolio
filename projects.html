Whisk&Brew
W&B
Whisk & Brew is a responsive café discovery website designed and engineered from scratch using semantic HTML5 and custom CSS3. The platform categorizes diverse culinary offerings using a warm, theme-driven visual identity. Key features include dynamic product cards, localized pricing modules, fluid cross-device navigation, and interactive CSS micro-animations. Developed as a hands-on technical challenge, this project demonstrates a strong command of modern layout systems, responsive web design (RWD), and iterative design refinement.
